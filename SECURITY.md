# Security policy

This repository publishes a static research website. Only the current published version is maintained.

Please report potential vulnerabilities through GitHub private vulnerability reporting:
https://github.com/neuro-Affect/neuro-affect.github.io/security/advisories/new

Do not include passwords, tokens, personal research data or exploit details in public issues. Include the affected URL, reproducible steps and expected impact in the private report. Avoid disruptive testing and testing GitHub infrastructure outside this website.
